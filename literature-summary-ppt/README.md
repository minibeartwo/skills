# 文献总结与汇报 PPT

完整阅读用户提供的学术文献，先生成高信息密度的中文极简总结，经过用户确认后，依次制作普通版和深圳大学模板版文献汇报 PPT。

技能标识：`literature-summary-ppt`。

## 最终成果

1. `总结.docx`
2. `发表年限-发表期刊-文章题目.pptx`
3. `发表年限-发表期刊-文章题目-深大模板.pptx`

文件名中的发表年限、期刊和题目以论文正式出版信息为准。

## 运行条件

- 支持读取 `SKILL.md` 和本地资源的 AI 客户端。
- 用户提供完整论文 PDF，以及可用的补充材料；普通版可另提供视觉参考。
- 可生成整页高清图片的内置生图能力。原始提示词指定 image2，技能允许使用当前环境内置生图模型；Python 依赖不会提供此能力。
- 可创建、读取并渲染 Word 和 PowerPoint 文件的运行环境。自动校验不能替代逐页视觉检查。
- 运行所附校验脚本时使用 Python 3.10 或更新版本，并安装以下依赖：

```bash
python -m pip install -r requirements.txt
```

`requirements.txt` 只列出所附 Python 脚本的第三方依赖，不包含客户端生图服务或文档渲染工具。

## 使用示例

安装整个技能目录后，向客户端提供论文，并输入：

```text
使用 $literature-summary-ppt 阅读我上传的论文，先生成并展示总结 Word 预览，待我确认后，再依次制作普通版和深大模板版文献汇报 PPT。
```

## 执行顺序

完整阅读论文 → 生成并校验总结 → 展示总结 Word 预览 → 用户确认总结 → 生成普通版全部预览 → 用户确认普通版 → 生成并校验普通版 PPTX → 从普通版迁移内容并生成深大模板版全部预览 → 用户确认深大版 → 生成并校验深大模板版 PPTX。

总结、普通版和深大版的确认分别针对最新预览。三个确认互相独立，不能提前授权、用沉默推断或相互替代。详细规则以 [`SKILL.md`](SKILL.md) 和 [`references/串行生成与确认规则.md`](references/串行生成与确认规则.md) 为准。

## 资源说明

- `agents/openai.yaml`：技能名称、简述和默认调用提示。
- `assets/深圳大学原始模板.pptx`：深大模板版的唯一模板来源。
- `references/`：原始提示词、总结质量规则、串行确认规则和模板页面映射规则。
- `references/原始文件/`：两份原始 Word 提示词及 SHA-256 校验值。
- `scripts/`：提示词一致性、总结质量、生成阶段和深大大纲对应关系检查。

两份原始提示词是权威文本，应完整保留；本说明不替代或改写它们。深大版内容只能来自已完成并校验通过的普通版 PPTX。

## 校验命令

以下命令从技能目录运行。示例中的 `work/` 和 `outputs/` 为任务工作目录，实际执行时可使用对应的绝对路径。

执行工作流前，检查两份 Markdown 提示词是否与原始 Word 文档逐字一致：

```bash
python scripts/检查提示词一致性.py
```

该脚本同时刷新 `references/原始文件/校验值.json`。普通检查不要使用 `--写入`；该选项会从原始 Word 重新生成 Markdown 提示词。

检查生成的总结：

```bash
python scripts/检查总结质量.py outputs/总结.docx --报告 work/总结质量报告.json
```

初始化和读取生成阶段：

```bash
python scripts/检查生成阶段.py --状态文件 work/文献汇报生成阶段.json --动作 初始化
python scripts/检查生成阶段.py --状态文件 work/文献汇报生成阶段.json --动作 状态
```

阶段推进命令见 [`串行生成与确认规则`](references/串行生成与确认规则.md)。确认动作必须记录用户针对对应最新预览的明确确认原文。

检查最终深大模板版封面和大纲与章节页标题：

```bash
python scripts/检查深大模板大纲对应关系.py outputs/最终深大模板版.pptx
```

自动检查通过后，仍需核对论文事实并逐页检查文档或演示文稿的渲染结果。
