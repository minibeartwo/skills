# 总结文献和制作PPT

## 权威来源与执行前检查

本技能包含两个用户提供的原始提示词。原始提示词是权威文本，不得删减、概括、翻译、改写、重排或合并。执行前必须运行：

```text
python scripts/检查提示词一致性.py
```

只有检查通过后才能继续。

按当前阶段完整读取以下文件：

- 制作总结前，读取 [总结文档原始提示词.md](references/总结文档原始提示词.md) 和 [总结文档生成与校验规则.md](references/总结文档生成与校验规则.md)。后者只规定生成过程、Word版式和质量验收，不替代原始提示词。
- 生成普通版页面预览前，读取 [文献汇报PPT原始提示词.md](references/文献汇报PPT原始提示词.md)。
- 开始任何演示文稿工作前，读取 [串行生成与确认规则.md](references/串行生成与确认规则.md)。
- 开始深大模板版工作前，读取 [深大模板页面映射规则.md](references/深大模板页面映射规则.md)。

## 最终成果

最终生成三份文件：

1. `总结.docx`
2. `发表年限-发表期刊-文章题目.pptx`
3. `发表年限-发表期刊-文章题目-深大模板.pptx`

发表年限、期刊和文章题目必须通过完整阅读论文及其正式出版信息确定，不能照抄上传文件名或占位文字。只有文件名非法字符允许替换。

## 不可跳过的顺序

严格串行执行：

`读取完整论文 → 生成并校验总结 → 展示总结Word预览 → 等待总结确认 → 生成普通版全部预览 → 等待普通版确认 → 生成并校验普通版PPTX → 生成深大模板版全部预览 → 等待深大版确认 → 生成并校验深大模板版PPTX`

使用 `scripts/检查生成阶段.py` 维护任务状态。不得提前创建候选文件、空壳PPTX或通过并发规避门禁。

## 第一阶段：完整阅读论文

完整阅读正文、方法、结果、图表、图注、补充材料和局限性，建立事实清单：

- 正式发表年限、期刊、题目；
- 研究问题、空白和研究设计；
- 数据来源、样本量、队列与数据集划分；
- 方法或模型的输入、输出、结构和主要任务；
- 每项核心结果对应的数据集或队列、比较对象、指标、关键数值和原文支持的意义；
- 创新、局限和可由原文支持的价值；
- 每页结果拟使用的论文图号和分图编号。

不得编造论文没有的数据、结论、临床意义或引用。

## 第二阶段：生成并确认总结文档

逐字使用 `references/总结文档原始提示词.md` 的完整内容，并遵守 `references/总结文档生成与校验规则.md`：

1. 先基于事实清单写完整版本，再压缩到500字以内；不得把“极简”理解为尽量少写。
2. 文章信息充足时，四部分正文默认写到约450—500个汉字；低于约420个汉字不得直接通过。
3. 每条结果必须保留数据集或队列、比较或指标、关键数值和明确的解释性结论。
4. Word采用用户示例所示的紧凑中文汇报版式，不加入额外居中英文副标题。
5. 生成后运行：

```text
python scripts/检查总结质量.py outputs/总结.docx --报告 work/总结质量报告.json
```

6. 质量检查通过后，把Word渲染为页面图片并逐页检查；再使用 `检查生成阶段.py` 记录总结预览。
7. 向用户提供 `总结.docx` 和全部Word预览图，然后停止。用户确认前禁止开始普通版PPT预览。
8. 用户要求修改时，只修改总结，重新校验并重新展示最新Word预览。

## 第三阶段：生成普通版全部预览图

用户明确确认最新总结预览后，逐字使用 `references/文献汇报PPT原始提示词.md`。先说明计划页数、逐页标题、主要内容和拟使用的论文图号，再生成全部页面。

每一页完整预览图都必须通过 image2 或当前环境内置生图模型生成。论文真实图表可以作为参考素材，但不得用程序化页面排版冒充生图预览，也不得用生成图替换论文结果数据。

提供全部高清预览和总览拼图后停止。此时禁止：

- 创建普通版PPTX、隐藏草稿、候选PPTX或空壳PPTX；
- 开始深大模板版；
- 把总结确认当作普通版确认。

只有用户看过最新全部预览后明确回复“确认”“同意”或“可以生成PPT”等同意语句，才能继续。

## 第四阶段：生成普通版PPTX

普通版预览确认后，使用全部已确认高清页面生成PPTX，默认每张图作为一页完整画面，并把逐页讲稿写入备注。

完成后渲染全部页面，与已确认预览逐页比较。普通版未生成并校验通过前，不得开始深大模板版。

原始PPT提示词中的“只要高清PPT页面图片，不要可编辑PPT”完整用于预览阶段；PPTX是用户确认预览后的封装成果，不构成对原始提示词的修改。

## 第五阶段：生成深大模板版全部预览图

深大模板版必须读取已经完成并校验通过的普通版PPTX，并把它作为唯一内容上游。不得重新独立策划内容，也不得与普通版并行。

使用 [深圳大学原始模板.pptx](assets/深圳大学原始模板.pptx) 的真实页面作为视觉基础，按照 `references/深大模板页面映射规则.md` 迁移普通版的标题、结论、论文图、关键数值、引用和讲稿。

每页完整预览也必须通过 image2 或内置生图模型生成。提交全部预览和总览拼图后停止；用户确认前禁止创建深大模板版PPTX。普通版确认不能替代深大版确认。

## 第六阶段：生成深大模板版PPTX

深大版预览确认后，从 `assets/深圳大学原始模板.pptx` 复制母版和对应页面，再写入确认后的页面内容。不能新建仅颜色相似的演示文稿代替原模板。

运行：

```text
python scripts/检查深大模板大纲对应关系.py 最终深大模板版.pptx
```

修复全部错误后，渲染并检查每一页：

- 封面主标题为“文献分享”；
- 所有实质正文页使用模板第二页；
- 第三页结构大纲设计未改变；
- 大纲章节名称与后续对应章节页完全一致，不依赖绝对页码；
- 普通版内容、论文图、图号、关键数值、引用和讲稿完整迁移；
- 校徽、页脚、上下红色区域和结束页保持原模板结构。

## 交付

只有总结、普通版和深大版三个预览确认门禁均通过，并完成最终校验后，才交付三份最终成果。过程预览、状态文件和校验报告默认保留在工作目录，除非用户要求，不作为最终成果交付。
