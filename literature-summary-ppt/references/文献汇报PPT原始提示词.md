请帮我制作一组【PPT页面图片】而不是可编辑PPT，主题是：【这里填写论文名称 / 研究主题】。

用途是：【组会汇报 / 文献分享 / 课程汇报 / Journal Club】。

受众是：【研究生 / 临床老师 / 课题组成员 / 有一定生信基础但不熟悉该研究的人】。

输出要求

只要【高清PPT页面图片】，不要可编辑PPT。

生成【X张】，比例【16:9 横版】。

每张图都要像一页完整PPT，而不是单独插图。

最终请同时给我：

全部页面图片

一个 zip 压缩包

一份逐页演讲稿 / 汇报讲稿

如有需要，再附一份图源说明。

内容要求

请先完整阅读论文，并按照适合文献汇报的逻辑设计页面，建议包括：

封面

研究背景与科学问题

研究思路 / 整体技术路线

样本与数据来源

主要分析方法

核心结果1

核心结果2

核心结果3

关键机制 / 主要发现总结

论文创新点

论文局限性

总结与启发

参考文献 / 资料来源（可选）

具体页数和结构请根据论文内容灵活调整，不需要机械套用。

结果解读要求

结果部分是整套PPT的重点。

不要只是把论文中的 Figure 截图放进去，要帮助听众理解：

作者为什么做这一步；

用了什么方法；

这张图怎么看；

得到了什么结果；

这个结果说明了什么。

每页尽量只讲一个核心结论。

结果页标题尽量使用【结论型标题】，而不是简单写“Figure 1”“实验结果”等。

图源要求

这一点很重要：

PPT中的结果图片，优先使用论文中的真实 Figure / Panel。

不要随便找其他论文的结果图代替。

如果我上传了论文PDF，请优先直接从论文中选择合适的 Figure。

可以根据排版需要，对原 Figure 进行：

裁剪

放大

重新组合 Panel

增加箭头、框选和中文注释

但不要修改原始数据表达。

每页如果使用论文原图，请标注：

【Figure X / Figure Xa-Xc】

以及简单的文献来源。

如果需要补充研究背景图片，可以使用其他可靠文献或官方资料，并注明来源。

版式要求

整体风格参考我上传的模板。

每页要有明确标题。

重点词用【红色 / 加粗】突出。

尽量采用【左侧文字 + 右侧论文结果图】布局。

也可以根据图片特点调整为上下布局或多图组合。

不要堆太多字，要适合组会或课堂讲解。

论文结果图尽量放大，保证坐标、标签和图例能够看清。

整体风格要简洁、专业、科研感强，不要做成商业宣传PPT。

语言要求

中文为主，关键英文术语、基因名、细胞类型、通路名和分析方法保留英文。

不要直接把论文原文大段翻译到PPT中。

不要写成大段论文式表述。

要适合口头汇报，重点讲清楚：

“为什么做”

“怎么做”

“结果怎么看”

“说明了什么”

以及各个结果之间的逻辑关系。

演讲稿要求

每一页PPT都配一段对应的讲稿。

讲稿不要只是重复PPT上的文字，而是补充：

这一页应该怎么讲；

图应该怎么看；

重点应该放在哪里；

这一页和上一页、下一页如何衔接。

语言自然一些，适合真正站在组会上进行文献汇报。

额外要求

在正式输出前，请先告诉我：

你准备做几页；

每页标题是什么；

每页主要讲什么；

每页准备使用论文中的哪个 Figure / Panel。

然后再直接生成。
